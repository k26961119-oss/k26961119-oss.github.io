Finance Research Sync 隱私權政策

最後更新：2026 年 10 月 31 日

1. 應用程式用途

Finance Research Sync 是供管理者個人使用的 Windows 桌面研究工具，用於處理使用者有權使用的 公開財經節目內容、在本機產生逐字稿，以及將 成果同步至使用者授權的 Google Drive。

2. Google 使用者資料存取

本工具在使用者透過 Google OAuth 2.0 明確授權後， 使用 Google Drive API 存取必要的雲端檔案。

目前請求的 OAuth 權限為： https://www.googleapis.com/auth/drive

此權限可讓應用程式查看及管理使用者 Google Drive 中的檔案，授權範圍不限於單一資料夾。 本工具目前的同步操作則以使用者設定的研究資料夾 為目標，不主動刪除其他雲端檔案。

3. 資料使用方式

本工具可能在執行同步時處理以下資料：

  • Google Drive 資料夾及檔案名稱、ID 和中繼資料。
  • 使用者指定同步的 TXT、SRT、JSON 與 manifest 檔案。
  • 用於核對完整性的檔案大小及 SHA-256 雜湊。
  • OAuth 授權資訊及同步執行狀態。

以上資料僅用於使用者授權的檔案同步、 讀回驗證、錯誤處理及同步紀錄。

4. 資料儲存

逐字稿由使用者電腦上的本機轉錄程式產生。 使用者啟用同步功能後，成果會上傳至其授權的 Google Drive。

Google OAuth Token 與同步設定儲存在使用者 電腦的本機專案設定目錄中。 本網站不要求使用者上傳 Token、密碼或 Client Secret。

本工具目前沒有供開發者集中儲存使用者 Google Drive 檔案的獨立雲端伺服器。

5. 資料分享與使用限制

本工具不出售 Google 使用者資料，不將其用於廣告、 個人化行銷、信用評分或訓練通用 AI 模型。

資料僅在提供使用者要求的功能時， 依照其授權與相關服務互動，例如將指定成果 傳送至使用者自己的 Google Drive。

本工具對 Google API 資料的處理遵循 Google API Services User Data Policy ，包括適用的 Limited Use 要求。

6. 資料保留與刪除

本機逐字稿、同步紀錄及設定資料， 會保留在使用者自己的電腦上，直到使用者自行管理或刪除。 Google Drive 中的同步檔案由使用者透過其帳號管理。

使用者可以隨時在 Google 帳號的第三方應用程式連線設定 中撤銷授權，並自行刪除本機資料與雲端成果。 撤銷授權不會自動刪除已同步的檔案。

7. 本網站與第三方服務

本網站由 GitHub Pages 託管，只提供應用程式資訊， 不設置登入表單，也不使用自建廣告或分析追蹤工具。 GitHub 及 Google 可能依各自的政策處理服務存取資料。

8. 政策更新

如果本工具的資料存取或使用方式有重大變更， 將更新本政策；必要時重新取得使用者授權。

9. 聯絡方式

如有隱私或資料處理相關問題，可透過 GitHub Issues 聯絡維護者。請勿在公開 Issue 中提供密碼、 Token、憑證或私人逐字稿。
